- 🏗️ **Data Engineering & ETL/ELT:** Designing pipelines for extraction, transformation, and ingestion.
- ⚡ **Back-end Systems & Microservices:** Building robust APIs using C# (.NET) and Python (FastAPI/Django).
- 📊 **Big Data & Analytics:** Data manipulation and distributed computing with PySpark, Pandas, and SQL.
- 🤖 **Web Scraping & Automation:** Developing automated crawlers and integration scripts with Selenium & Python.
- 🧩 **Software Architecture:** Applying Clean Architecture, Domain-Driven Design (DDD), and SOLID principles.
- ☁️ **DevOps & Infrastructure:** Containerization with Docker, CI/CD automation, and cloud services deployment.
